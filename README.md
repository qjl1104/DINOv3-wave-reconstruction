# 波浪三维重建项目（Wave Reconstruction Project）

基于**双目立体视觉 + 示踪粒子跟踪 + DINOv3 语义特征 + 物理约束神经网络（PINN）**
的自由表面波场重建系统：从两台相机拍摄的水面粒子视频，重建连续波面高度场 η(x, y, t)。

**生产链**（`run_full_pipeline.py` 一键端到端，mtime 自动跳过期环节，`--force` 全量重建）：

```
原始图像 (left/right, 1000帧@50Hz)
  → v3 检测（白顶帽 + 局部极大值 + 分水岭拆粘连 + 亚像素质心，零形状先验）
  → 外观辅助重捕跟踪（连续帧 12px 紧门 + 断档 21×21 patch NCC≥0.55 验证；
     --no-foam 剔除 >1500px² 连通域天然水沫 + 带内外观分类泡沫）→ 跳切清洗
  → DINOv3 轨迹描述子（矫正系采样）→ 跨相机匹配（几何判据 + 视差平面先验，
     匈牙利一对一最严口径）→ 三角测量（3D 轨迹片段 977 条 / 29.2 万点）
  → 相干性验证（互谱相位法：c = 2009 mm/s，95% CI [2008,2009]，理论 1976）
  → PINN（互谱测向旋转传播坐标系 + c 固定互谱实测，片段级留出 R²=0.949）
  → 波成分场（f=0.797Hz, λ=c/f=2523mm, 中心振幅 39.0mm/理论 40）
```

> 大量漏检。经人工计数基准（直接看图数粒子）与全链路 A/B 实验，形成完整判决链：

## 物理原理总览

整条流水线的物理链条：

```
标定几何（针孔模型 + 对极几何）
   → 粒子示踪（波面的拉格朗日采样）
     → 三角测量（空间射线求交）
       → 波动方程约束的场重建（PINN）
```

水面本身透明、镜面反射、无可匹配纹理，无法直接做立体视觉；
浮性示踪粒子提供可跟踪的纹理点，并假设粒子跟随自由表面运动
（浮力 + 表面张力约束，滑移可忽略），因此粒子位置即波面的离散采样。
注意这给出的是**拉格朗日**数据（跟随粒子的轨迹），而非固定网格上的欧拉场。

**精度链条的物理约束**：本装置 Z≈4.8–6.4m，**每 ±1px 的视差/定位
误差 ≈ ±6–13mm 深度噪声**（δZ = Z²/(bf)·δd，bf=3.72e6），波幅 ~40mm
——本质是**亚像素精度的游戏**。这一条物理约束判决了所有技术路线的可行性（见"路线判决记录"）。

## 生产管线详解

### 1. 相机标定 `camera_calibration/`

物理模型：针孔投影 `x_pixel ~ K·[R|t]·X_world` + 径向/切向畸变。

- 输出内参 K1/K2、畸变系数、外参 R/T，并导出投影矩阵
  P1 = K1·[I|0]、P2 = K2·[R|T] 与基础矩阵 F
- 标定结果：`camera_calibration/params/stereo_calib_params_from_matlab_full.npz`
- 标定重投影误差决定整个几何链的精度上限
- 基线 1413mm，矫正后视差约 565–781px（随位置变化，对应 Z≈4.8–6.4m）

### 2. 粒子检测 `particle_processing/02*`（2026-07-29 v3 重构）

**生产：`02c_detection_v3_localmax.py`**（零形状先验）。物理依据：标识物圆片
经相机斜视+局部侧倾成像为椭圆（实测轴比中位 0.68），粘连团更无形状可言，
v1 的圆度/凸度/惯性比过滤召回仅 ~31%（人工计数基准）。
流程：原始图按标定 remap 矫正 → 白顶帽（31px，替代背景建模；预处理右图
已被 CLAHE 放大纹理毁掉，v3 不依赖 00/01 预处理）→ 自适应阈值局部极大值
→ 多峰连通域内分水岭拆粘连 → 盆地面积 ∈[12,800]px² 过滤 → 强度加权
亚像素质心。每点附 meta（area/peak/contrast/big_comp）。
产出：左 977 / 右 1322 点/帧（v1 为 158/186），召回 ~95%。
泡沫过滤：`--no-foam` 剔除 big_comp≥1 的检测点（big_comp=1：连通域
>1500px² 的天然水沫团，核验精度 100%；big_comp=2：中间带 [500,1500)px²
经外观分类器判定的水沫，特征 n_peaks+边缘梯度，42 个人工标注 LOO 90.5%）。
亮度判据已被数据推翻（水沫与暗标识物分布重叠），未使用。

历史记录（存档）：`02_particle_detection.py`（SimpleBlobDetector 严格形状
过滤，v1 生产）；`02b_detection_v2_loose.py`（放宽形状过滤，召回 ~48%，
实验证实形状路线天花板，已被 v3 取代）。

### 3. 单相机 2D 时序跟踪 `particle_processing/03*`（2026-07-29 重构）

**生产：`03b_tracker_appearance.py`（外观辅助重捕）**。架构依据（全链 A/B
实验结论）：纯距离关联在高密度下没有可行窗口——门必须 ≥ EKF 预测误差
（断档后 ~40px）又 < 泡沫间距（v3 密度下 ~15-29px），两者不相交
（dt80 身份碎裂 36 刀/条、dt40 右侧崩坏、dt20 双侧雪崩，均已实证）。
设计：EKF(匀速) + 两级稀疏二部匹配（KDTree 候选 + csgraph，替代全稠密
匈牙利）——① 连续帧关联：12px 紧门（实测粒子帧间运动 p99=2.3px，身份
极纯）；② 断档重捕：50px 粗筛后必须 21×21 patch NCC≥0.55 验证
（同相机时序外观稳定，距离不可信时看内容），模板随每次匹配亚像素刷新；
`--no-foam` 剔除 big_comp≥1 检测点。输出与旧 03 兼容（Track/.points），
下游 jumpcut/匹配零改动。效果（v3 检测输入）：身份碎裂 0.5-0.9 刀/条、
段数/点数 8-30 倍于旧链、≥100 帧长片段 421 条（旧 21）。

历史记录：`03_trajectory_tracking_2d_KLF_opus.py`（EKF+全稠密匈牙利，
纯距离关联，v1 生产；max_age=20/min_hits=5/dist_thresh=80 曾在低密度
实测为甜点——该甜点只在低密度成立）。
⚠ **跳号污染与跳切清洗（2026-07-23）**：`clean_tracks_jumpcut.py` 在 >12px
（跨断档按 4px/帧放宽）跳变处切开、丢弃 <20 帧碎段，产出身份干净段——
该判据对新旧跟踪器均适用，仍为生产环节。

### 4. 跨相机轨迹匹配 `particle_processing/`

**几何版：`rematch_rectified.py`**（替代旧 `04_*` 与 `05_*`）。
旧 `04_trajectory_matching.py` 的"左右轨迹起止点像素距离 < 200px"预过滤
在物理上错误（本系统视差数百 px，正确匹配被系统性误杀）。
修正版：canonical 2D 轨迹点**本就在 npz 矫正坐标系**（实证：轨迹点 vs
矫正图 blob 中位 1.74px、92%<3px），直接用 dy≈0、视差为正且近恒定判据
按绝对帧号对齐匹配，三角化用矫正内参 K' 归一化 + `[I|0]`/`[I|t']` +
`R1ᵀ` 旋回，保留每点帧号；片段级匹配（短片段也接受）。
基线输出：70 条 3D 片段 / 12980 点 → `data/trajectories/trajectories_3d_v2.pkl`。

⚠ **跨相机匹配的根 bug 与修复（2026-07-23，本项目最深的坑）**：
长峰波上沿波峰（≈极线）方向的点对**同相振荡**——dy≈0、视差恒定两条
几何判据对【错误对】同样成立，匹配在该方向欠约束；DINO 轨迹描述子在
完全相同的白色泡沫间也不具区分度（相似度 ≥0.7 是"任意两泡沫"的地板，
不能当作匹配正确性证据）。旧链因此系统性接受了 d≈871px 的串号错配族，
造出整套幻影几何（Z≈4.3m、c≈730mm/s、λ≈0.93m 及"浅水"误判——
平面波表观速度沿任何轴不低于真实 c，曾据此误判深水理论被排除）。
修复：**位置相关视差平面先验**（`DISP_PLANE`，`fit_disp_plane.py` 从
紧窗可信片段 bootstrap 拟合，d = a·x+b·y+c 按左片段位置预测视差，
±15px 容差拒绝对），真家族 d≈565–781px（Z≈4.8–6.4m）。
验证：平面门拒绝 79 对（错配族）、保留 70+9 对；重投影中位 ~1.3px；
互谱相位 c=2048mm/s（理论 1976）；30mm 泡沫球按半浸有效可见直径 ~22mm
反推的视差平面与匹配平面同构（x 斜率≈−0.01、y 斜率≈+0.36）；
长片段 0.781Hz 振幅中位 ~37mm ≈ 波幅锚点 40mm。
另注：更早还曾把"未矫正原始系射线"与矫正系 P 阵混用（合成误差 ~22m），
已一并修复；重投影 1.46px vs 498px 为证——但重投影自洽≠匹配正确，
上述平面先验才是匹配正确的来源。

**生产匹配（2026-07-29 起）：`rematch_dino_v2.py --hung-only`**。
几何判据 + 视差平面先验之上，取匈牙利一对一最严口径（多对一匹配主要是
右侧轨迹碎裂的合法时间切片，但会带入额外噪声；一对一子集主峰率最高
93-94%）。输出 **977 条 3D 片段 / 29.2 万点** →
`data/trajectories/trajectories_3d_v3nf_hung_dino.pkl`
（互谱验证：c = 2009 mm/s，CI [2008,2009]，主峰率 94%）。
对照：`rematch_dino_v2.py` 不加 --hung-only 为候选+DINO 门模式
（修复坐标后相似度 med 0.755，2578 段/主峰率 88%/相位 RMS 61ms——
覆盖更大但噪声更高；生产维持 hung-only）。
描述子 `DINOv3/compute_desc_tracks.py` 已修复为**矫正系采样**
（旧版在原始图上按矫正系坐标采样，错位 10-24px）。

旧流程（存档参考）：`04_*` 对极约束 + DTW；`05_reconstruction_3d.py`
用 `cv2.triangulatePoints`（但丢弃帧号）。

### 5. 波动场建模（PINN） `wave_modeling/`

**合成验证：`pinn_v2.py`**（06–09 是未跑通的草稿，保留仅供对照）。
合成行波上端到端验证：场重建网格 relL2 ≈ 2.3%，c 反演误差 <0.1%。

- 控制方程：线性波动方程 η_tt = c²∇²η，c 由互谱相位法实测给定
  （本数据 c≈2.0×10³ mm/s，深水色散 c=g/ω≈1976，见"验证体系"节）。
  可选 Boussinesq 色散修正 +(h²/3)∇²η_tt
  （逼近完整 Airy 色散 ω² = gk·tanh(kh) 到 O((kh)²) 阶；
  h 必须显式传入、单位与坐标一致，无默认值以防 mm/m 混用）
- 网络：Fourier 特征（可学习频率）+ tanh MLP，输入内部归一化
- 双重损失：数据损失 + 自归一化 PDE 残差（配置点逐 epoch 重采样）
- 关键实践经验（详见 `pinn_v2.py` 文件头注释）：
  ① Fourier 特征的 sigma 必须贴近且不超过目标谱，过大会逐点背诵不泛化；
  ② 波幅 ~1e-3 m 必须归一化，否则坍缩到 η≡0 平凡解；
  ③ 物理损失需按首值自归一化，固定权重会被二阶导数的 ω² 放大压垮。

**真实数据实验：`run_real_pinn.py`**（生产数据 `trajectories_3d_v3nf_hung_dino.pkl`）。
流程：PCA 主平面 → 法向残差 η → MAD 离群剔除 → 逐片段去中位数（debias）→
跨片段去重 → **互谱相位法测传播方向并旋转到传播坐标系**
（ξ 沿传播，各向异性 Fourier sigma=(0.5,0.3,8.0)，按各维目标谱周期数推导，
推导注释在 run_real_pinn.py）→ **片段级**留出评估。

- **c 固定为互谱实测值（`--c` 可覆盖）**：可学习时反演不可辨识
  （曾被噪声宽带模态拖走），故 c 由互谱相位法独立测量、
  物理损失只承担时空相干性约束。`--tag xxx` 输出到 `pinn_real_xxx.pt`
  避免覆盖生产产物。
- **片段级留出评估**（seed 固定；PCA 平面、MAD 阈值、归一化 bounds 仅拟合
  训练侧，防泄漏）。**当前结果：留出片段 R² = 0.949**
  （train 1386 段 26.9 万点 / test 346 段 7.3 万点，η std 两侧 30.1/30.0mm）——
  轨迹级演进：0.196（跳切前）→ 0.456（跳切后）→ 0.854（v3+外观跟踪）→
  **0.949**（再加泡沫过滤）。
- 轨迹间常值偏移：曾 560→128→37→19mm（错配/跳切修复），v3 含泡沫时
  回升到 31.9mm，泡沫过滤后 21.8mm。偏差场检验（2026-07-29）：该偏移在
  世界系/像面坐标下均无空间结构（平面梯度 ~1mm/m）——**逐轨迹随机偏移，
  非标定系统场**，逐片段中位数 debias 仍为正确处理；根治靠提高单轨迹
  三角化精度。已知疑点：短片段携入的独立偏差偏多。
  去中位数工程性扣除（平均水面已知是平的，不损失波动信息）；偏差场检验
  已排除"静态空间场"假说，静水参考帧/重标定对这类随机偏移无直接作用。
- 另一已知现象：长轨迹原始谱被 0.05–0.08Hz 低频漂移主导——
  相机热胀冷缩导致主点漂移，师兄论文亦记载（建议预热相机）；
  分析时用 [0.5,1.2]Hz 带通取波成分。

### 6. 全链路复现与最终重建 `run_full_pipeline.py` + `final_visualize.py`

`run_full_pipeline.py`（根目录）一键端到端 7 阶段（2026-07-29 新配方）：
v3 检测 → 外观跟踪（--no-foam）→ 跳切清洗 → DINO 描述子（矫正系采样）→
匈牙利一对一匹配 → 互谱裁判 → PINN → 最终可视化。
各阶段按 mtime 判断：输入比产物新才重跑，否则跳过；`--force` 强制全量重建。

## 验证体系：互谱相位法（本项目的"判官"）

**原理**：示踪粒子水平位置近似不动，其 η(t) 是 0.79Hz 单频振荡，
相位由沿传播方向的位置决定。对时间重叠充分的轨迹对，在重叠窗口内求
0.79Hz 处**互谱相位差**（arg(A·conj(B))，等效于用全部重叠样本的最优
相位估计）→ 时滞 τ_ij = Δx_ij·n/c，多对加权最小二乘解出相速度大小 c
与传播方向 n。周期模糊（τ±kT）用两遍展开：先近距对（|τ|<T/2 无模糊）
拟合初值，再对全部对选离预测最近的候选时滞重拟合，配 200 次 bootstrap CI
（注意 CI 偏乐观：bootstrap 重采样的轨迹对间强相关——每片段参与数十对，
且解缠绕不确定性未进入重采样）。

**断帧处理（2026-07 修）**：全部 79 条片段存在帧空洞（实测 958 个、最长
25 帧≈0.4 个波周期）。FFT/带通前先按真实帧号重网格化：≤4 帧空洞线性插值，>4 帧空洞
零填充——窄带单频信号下零填充相位近似无偏，而长空洞线性插值会注入错误
相位。τ 换算用实测主峰频率而非固定 0.79Hz。

**为什么用互谱相位而不用互相关 argmax**：带通后信号接近纯正弦，
余弦平台期导致 argmax 在不同周期间跳变（实测 c 从 2515 漂到 3706 mm/s，
方向轴倒转）；互谱相位用全部样本，是窄带信号的正确工具。

**实现**：`wave_modeling/diag_hovmoller_xcorr.py`（诊断）；
`wave_modeling/eval_tracks.py`（把 η std / 0.79Hz 主峰率 / 相位 c
打包成"同一杆秤"，可评估任何 3D 轨迹 pkl）。

**基线判决（2026-07-29 v3 链）**：c = **2009 mm/s（95% CI [2008, 2009]，
残差 RMS 44ms；主峰率 94%，有效片段对 70439 个）**，传播方向 (−0.514, 0.858)。
旧基线（2026-07-23 跳切修复）：c = 2033 mm/s（CI [2000,2070]，RMS 24ms，
有效对 88 个，主峰率 71%）——两个时代都把理论值 1976 包在 ~1.6-2.9% 内，
但统计功效差三个量级（CI 宽 70 → 2 → 1 mm/s）。测量史教训（c≈1900 巧合 /
c≈720 幻影 / 平面先验 2048 / 跳切 2033 / v3 链 2009）说明：**相位法只测量
"相位差 ÷ 空间距离"，空间距离错则一切皆错；它判得了方法，判不了匹配**。
全链路几何正确性的底层证据：重投影误差 ~1.3px + 标记物尺寸回归同构
（见第 4 节）+ 去偏 η std 29.0mm 落在正弦理论 28.3mm 附近。

**Hovmöller 显示陷阱（已修）**：旧 `field_comparison.png` 面板看似
"画得太满、静态梯度"，根因是绘图 bug——`fig.colorbar(im2, ax[2])`
把 ax[2] 当作位置参数 `cax`（色条画进指定 axes），整条色带盖住了
Hovmöller 面板；改 `ax=ax[2]` 修复（run_real_pinn.py 内有注释警示）。
细分箱（100mm×0.1s）占用率仅 11.8%，数据稀疏是事实。

## 路线判决记录（全部被互谱相位检验定量裁决）

### FoundationStereo 稠密路线（否决）

`foundation_stereo_test/` 完整部署（venv `.venv_fs`）：几何层面成功
（视差 100% 稠密、深度 4–9m 合理、热态 1.6s/对），但 20 帧时序残差实验：
固定系统偏差 ~141mm + 帧间涨落 ~69mm 的噪声地板，比波幅大一个量级——
瓶颈不是像素噪声而是网络在粒子间无纹理区的"假想面"偏差。
稠密路线若要可用需静水参考帧扣偏差 + 域自适应微调。

### PI-DINOv3 学习式匹配（逐帧立体：否决）

`DINOv3/` 完整流水线（冻结 DINOv3 特征 + 1D 相关体 + Sinkhorn +
几何指纹融合，自监督训练，详见其自带 README）。
`batch_pointcloud.py` 全部 1000 帧批量推理（187,729 点，~188 点/帧），
`diag_dinov3_coherence.py` 以 250mm 网格节点当"虚拟浪高仪"做相位诊断：

- **0% 节点的 FFT 主峰落在 0.79±0.1 Hz**（粒子链带通后中位 0.792 Hz）
- 去静态偏差后节点逐帧残差 std = **458mm，是波幅的 11 倍**；
  静态偏差场本身 std 539mm（−1731..+1273mm）
- 0.79 Hz 互谱相位拟合 c = 14.6 m/s——相位无结构，纯噪声

物理根源：soft-argmax 在 16px patch 相关上的视差精度是 patch 量级
（自评 disparity jitter ~7px/帧）→ ±237mm 深度噪声（34mm/px × 7）。
**判决：DINOv3 逐帧点云不能并入 PINN 训练集。**

两轮修复（均实测否决）：
① snap 亚像素细化（`refine_subpixel.py`）：训练头预测位置 97% 不落在
任何右图 blob ±8px 内——粗匹配本身就不可靠，无从细化；
② 描述子最近邻（`match_descriptor_nn.py`，DINO 特征双向互查 +
Lowe ratio + NCC 复核）：~35 匹配/帧、相似度中位 0.774，
15% 节点出现 0.79Hz 主峰（vs 0%），但 0.79Hz 振幅中位仅 3.4mm、
c 拟合仍无结构。深度分布与粒子链一致（中位 6.1m vs 6.3m）——
**近平面表面上，错匹配产生的 3D 点空间上看着合理（其波长评估只差
15% 的原因），但时间不携带真实局部运动**，互谱相位检验正是抓这一点。

### DINOv3 描述子时序跟踪替代 KLT（否决）

`track_descriptor.py`（缓存关键点 + 描述子，匈牙利帧间关联）轨迹量是
KLT 的 10 倍，`match_dino_tracks.py`（匈牙利 1-to-1）得 336 条 3D 片段 /
11.3 万点，去偏 η std≈50mm、38–51% 片段见 0.79Hz 主峰——但**互谱相位
完全无结构**（c 拟合 8.7–34 m/s 均为噪声）。根因是**身份扩散**：轨迹在
相似 blob 间以每次 <8px 的小步随机游走，频率与振幅对（都在 0.79Hz 振荡）
但相位游走（片段内前后半段相位差中位 62°，仅 14% <1rad）。三轮修复
（匈牙利全局指派 / 门控 25→8px 随断档缩放）都只能缓解不能根治：
KLT 锁的是图像块内容本身，描述子在重复纹理上的区分度救不了相位。
**对测波而言相位就是信息本身，故否决。**

见"生产管线详解 第 4 节"——轨迹级描述子相似度复核 + 边界救回。

### 2026-07-29 检测/跟踪体系判决（本轮新增，全部同一杆秤）

**检测路线**：
- v1 严格形状过滤（否决）：召回 ~31%（人工计数基准），形状先验物理不成立（椭圆成像）；
- v2 放宽形状过滤（否决）：召回 ~48%，且下游纯距离跟踪碎裂（36 刀/条），
  长片段 21→10、有效对 88→24——检测红利被跟踪吃掉；
- **v3 零形状先验（采用）**：召回 ~95%，左 977/右 1322 点每帧。

**跟踪架构**：
- 纯距离关联（否决）：关联门无可行窗口（≥EKF 预测误差 ~40px 且 < 泡沫间距
  ~15-29px，dt80 碎裂/dt40 右崩/dt20 雪崩）；
- **外观辅助重捕（采用）**：紧门 12px + NCC≥0.55 重捕，碎裂 0.5-0.9 刀/条，
  全部裁判指标数量级改善。

**泡沫判据**：
- 连通域 ≥1500px²（采用）：核验精度 100%；
- 亮度判据（否决）：水沫与暗标识物分布重叠，中位数几乎相同；
- 中间带外观分类（采用）：n_peaks+边缘梯度，LOO 90.5%。

**静态偏差场假说（否决）**：轨迹间偏移在世界系/像面坐标均无空间结构
（梯度 ~1mm/m），逐片段中位数 debias 保持。

**匹配口径**：匈牙利一对一（采用，主峰率 93-94%）优于候选+DINO 门
（85%，覆盖更大但噪声更高）。

**DINO 描述子采样坐标（修复）**：原始图→矫正图采样（错位 10-24px 消除）。

## 关键物理假设与误差来源

| 环节 | 假设/误差源 | 控制手段 |
|---|---|---|
| 标定 | 重投影误差 | 多姿态标定板、覆盖整个视场 |
| 采集 | 两相机**硬同步** | 同步触发；不同步会使运动粒子三角测量错位 |
| 采集 | 相机热漂移（0.05–0.08Hz 低频） | 预热相机；分析时带通剔除 |
| 示踪 | 粒子无滑移跟随水面 | 选用中性浮力/浮性粒子、足够小 |
| 检测 | 亚像素定位精度；形状先验物理不成立（椭圆成像） | v3：零形状先验（顶帽+局部极大值+分水岭） |
| 采样 | 帧率 vs 波频（Nyquist）；粒子密度 vs 空间分辨率 | 实验设计 |
| 跟踪关联 | 纯距离门在高密度下无可行窗口 | 外观辅助重捕（紧门+NCC 验证） |
| 检测污染 | 天然水沫团（变形、质心漂移）混入标识物 | 连通域面积 + 带内外观分类（--no-foam） |
| 三角化 | 逐轨迹随机常值偏移（~21.8mm std，非空间场） | 逐片段 debias（偏差场假说已证伪） |
| 匹配 | 长峰波沿波峰方向匹配欠约束（串号错配） | 视差平面先验 `DISP_PLANE`（rematch_rectified.py） |
| PINN | 线性波动方程 + 固定 c（互谱实测） | 深水成立；浅水/非线性需换 Boussinesq 或更高阶模型 |

## 参考文献与开源工具

**立体波面测量（经典方法）**
- Benetazzo (2006), *Measurements of short water waves using stereo matched image sequences*, Coastal Engineering（WASS 系统）
- Wanek & Wu (2006), *Automated trinocular stereo imaging system for 3D surface wave measurements*, Ocean Engineering（ATSIS）
- de Vries et al. (2011), 立体视觉测自由表面波高
- Gallego et al. (2014), *Space-time ocean wave measurement using variational stereo*

**折射/纹影法（单相机测波面坡度，实验室水槽适用）**
- Moisy, Rabaud & Salsac (2009), *A synthetic Schlieren method (FS-SS)*, Experiments in Fluids
- Gomit et al. (2013), *Free surface measurement by stereo-refraction*, Experiments in Fluids

**PINN 与波动建模**
- Raissi et al. (2019), *Physics-informed neural networks*, JCP
- Sallam (2024), *PINN + Fourier features 从水平速度反演波面*, arXiv:2409.19851
- Haitsiukevich & Ilin, *bif-PINN 求解自由表面水波问题*, JCP
- [DeepXDE](https://github.com/lululxvi/deepxde)：PINN 快速实验框架

**开源工具**
- 检测/跟踪：[TrackPy](http://soft-matter.github.io/trackpy/)（Crocker–Grier 亚像素检测 + Crocker–Grier/LAP 链接）

- 稠密立体匹配：RAFT-Stereo、[IGEV-Stereo](https://github.com/gangweiX/IGEV)、[FoundationStereo](https://github.com/NVlabs/FoundationStereo)（zero-shot，已判决不适用）
